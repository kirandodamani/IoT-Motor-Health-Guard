# Contributing

Contributions are welcome. For a focused change, create a branch, keep commits small, and explain how you tested the change in the pull request.

## Before opening a pull request

1. Do not commit Wi-Fi credentials, MQTT passwords, or device IDs.
2. Test firmware changes on the intended ESP32 board when hardware is available.
3. Keep telemetry keys backward-compatible, or document the migration in the pull request.
4. Update the README or relevant documentation when setup, wiring, or behavior changes.

## Reporting an issue

Include the ESP32 model, sensor model, wiring details, Serial Monitor output, and steps to reproduce. Remove credentials and other sensitive details first.
